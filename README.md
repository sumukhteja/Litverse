# Litverse

A simple, lightweight place for reading and writing poetry and fiction.
This platform is completely static, built with plain HTML, CSS, and JavaScript. It does not use any heavy frameworks or tracking scripts, keeping the focus entirely on the literature.

## How to use
- Open index.html in a web browser to run the application locally.
- Use read.html to view the curated library of poems and short stories.
- Use write.html to check the submission guidelines and submit your work.
All content is managed through simple, static HTML files and a client-side search index.
